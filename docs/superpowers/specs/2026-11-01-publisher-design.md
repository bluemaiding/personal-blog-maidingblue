# 本地博客发布面板

用户确认的方向：双击打开、本地运行，上传文件后选择文章 / Wiki、分类，预览、保存并推送 GitHub。补充要求：DOCX 保持原字体，Markdown 保留 LaTeX。

采用 Node 内置 HTTP 服务和浏览器界面，复用现有 Pandoc、索引脚本及 Git 登录。相较打包 exe，更新无需重新打包；相较线上后台，无需把仓库写入凭证交给网站。

## 界面

浅绿、浅橙底色，蓝色文字。文件、发布位置、标题、类别、年份、文体、语种直接展示；Wiki 展示实际三大类及可编辑分组。支持 MD、TXT、DOCX，附加图片选择。独立的预览、保存、发布并推送及重试推送按钮；显示真实处理步骤。

## 内容与格式

- 标题优先文件 frontmatter / 文内标题，可编辑；原文件不改。
- DOCX 读取 OOXML 样式继承、主题字体、段落及局部字体，用内联字体声明保留；依赖访问者设备安装字体，不自动分发商业字体。Pandoc 负责正文、列表、表格、图片、公式转换。
- Markdown 的四种数学定界符在转换中保留；文章加载 KaTeX，Wiki 使用现有渲染器。代码内公式保持字面量。预览使用实际生成结果。
- 编号自动递增；Wiki 使用稳定 ASCII 文件名防止改变既有深链。只新建，不静默覆盖文章。
- 只更新对应文章 / Wiki 索引；只计算新增文章的字数，避免全库重写。

## 发布与错误

仅绑定 127.0.0.1；写入接口校验会话及来源；上传文件名与附件路径检查。Git 提交限定本次保存文件，提交时停用自动推送 hook，由面板显式 push。检查已有暂存区、分支及远端；不自动合并冲突、不强制推送。失败保留本次保存清单及提交状态，重试不重复发文。预览和仅保存不提交。日志不记录凭证。

## 验证

隔离临时仓库测试文章与 Wiki 保存、索引、附件、DOCX 默认/段落/局部/中西文字体、数学、推送至本地 bare 远端及失败重试。Playwright 验证文件选择、分类切换、预览公式、按钮与错误状态；重跑现有文章筛选、Wiki 渲染回归。
