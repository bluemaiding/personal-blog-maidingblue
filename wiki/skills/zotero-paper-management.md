# 如何使用 Zotero 管理论文

> **核心问题：** 论文越下越多，散落在浏览器下载文件夹、微信传输助手、各个群聊里，找一篇上周看过的文章要花半小时。怎么把这些文献系统地管起来，还能在写论文的时候一键插入引用？

这篇笔记以一个问题为起点，从零搭建一套基于 Zotero 的论文管理工作流。不需要任何前置知识，只要你有"论文太多找不到"的困扰就够了。

## Zotero 是什么

Zotero 是一个**免费、开源**的文献管理工具，由 George Mason University 的非营利团队维护。它的核心能力是三件事：

1. **收集**——从浏览器、PDF、数据库一键抓取文献信息和全文
2. **组织**——用文件夹（Collection）、标签、搜索来管理成百上千篇文献
3. **引用**——在 Word 或 LibreOffice 里写论文时，一键插入格式正确的参考文献

它和 EndNote 做的事情一样，但完全免费，而且插件生态更活跃。对于本科生和研究生来说，Zotero 几乎是目前最优选。

## 安装与基本配置

去 [zotero.org](https://www.zotero.org/download/) 下载客户端，Windows / macOS / Linux 都有。安装完之后，**第一件事**是装浏览器插件（安装时会提示，也可以之后在 Zotero 的 编辑 → 设置 → 引用 → 浏览器插件 里找到）。

装好之后建议做三件事：

**1. 注册 Zotero 账号。** 客户端菜单栏点 编辑 → 设置 → 同步，登录你的 Zotero 账号。这样你的文献库会同步到云端，换电脑也不用手动导出了。免费账户有 300 MB 的附件存储，纯文献条目（不含 PDF 全文）不限空间。

**2. 设置附件存储位置。** 如果你不想把每个 PDF 都传到 Zotero 的服务器（毕竟 300 MB 不算多），可以在 编辑 → 设置 → 高级 → 文件和文件夹 里，把附件链接模式改成"存储文件副本的位置"，指向一个本地文件夹，再配合坚果云或 OneDrive 做同步。这是国内用户最常用的方案。

**3. 把默认 PDF 阅读器改掉。** Zotero 内置了一个还不错的 PDF 阅读器，但如果你习惯用其他工具，可以在 编辑 → 设置 → 常规 里设置"查看 PDF 时使用"为系统默认或指定程序。不过建议先试试内置的——它能直接在 Zotero 里做高亮、批注，而且批注会自动提取成笔记。

## 收集文献：从网页到 PDF

这是 Zotero 最让人上瘾的功能。几种常见的收集方式：

**浏览器一键抓取。** 在知网、Google Scholar、IEEE Xplore、arXiv 等学术网站上，浏览器工具栏的 Zotero 图标会自动变成对应的文献类型（期刊文章、会议论文、网页等），点一下就抓取了——标题、作者、年份、摘要、DOI、PDF 全文，全自动。

**拖拽 PDF。** 把 PDF 文件直接拖进 Zotero 主界面，它会自动识别 DOI 并从网上拉取元数据（标题、作者等）。识别不了的会保留为一个只有文件名的条目，你手动补一下就行。

**用 DOI 或 ISBN 手动添加。** 点工具栏的"通过标识符添加"（魔法棒图标），输入 DOI 号，Zotero 自动从 CrossRef 等数据库拉取完整的文献信息。这招适合处理别人发给你的 PDF 但元数据缺失的情况。

**知网文献的特殊处理。** 知网的元数据抓取偶尔会出问题（尤其是新版页面）。如果 Zotero 浏览器插件抓不到，可以先手动下载 PDF，再拖进 Zotero 让它自动识别。或者装一个 [Jasminum 茉莉花](https://github.com/l0o0/jasminum) 插件，专门增强知网的抓取能力。

## 组织文献：文件夹、标签与搜索

文献多了之后，组织方式决定了你找东西的效率。Zotero 提供三个层次：

**文件夹（Collection）。** Zotero 里叫"分类"，但本质上是文件夹。你可以建多级嵌套的分类，比如 `毕业论文 / 第一章-绪论`、`课程论文 / 信号与系统`。一篇文献可以同时出现在多个分类里（右键 → 添加到分类），不会被复制，只是多了一个"指针"。这比物理文件夹灵活得多。

**标签（Tag）。** 标签适合做跨分类的标记。比如你可以用 `#已读`、`#待读`、`#重要`、`#方法可复用` 来标记文献的阅读状态和价值。Zotero 支持自动标签（从文献信息里提取）和手动标签（你自己打的），建议以手动标签为主，不然标签列表会很乱。

**搜索与保存搜索。** 顶部的搜索框可以在当前分类或全部文献中全文检索。更强大的是"保存搜索"——你可以设定一组条件（比如：作者包含"王"、年份大于 2023、标签包含"待读"），把它保存成一个虚拟分类，Zotero 会自动把所有匹配的文献聚合在里面。这相当于一个自动更新的筛选视图。

一个实用的组织原则：**分类按"项目"分，标签按"状态"分。** 比如毕业论文、课程作业、竞赛各建一个分类；然后用标签标记读没读、重不重要。这样分类树不会太深，标签也不会太杂。

## 阅读与批注

Zotero 6 之后内置了 PDF 阅读器，体验已经相当好了。双击一篇文献就能打开，直接在 PDF 上高亮、加批注。

几个实用技巧：

**高亮颜色分类。** 黄色标结论、红色标问题、绿色标方法——你可以自定义一套颜色体系。右键高亮区域还能添加批注文字。

**从批注生成笔记。** 这是 Zotero 最强大的功能之一。在一篇文献的 PDF 里做完高亮和批注后，右键文献条目 → "从批注创建笔记"，Zotero 会自动把所有高亮和批注提取出来，生成一条独立的笔记，里面包含高亮原文、你的批注、以及出处信息。这样你写论文的时候，不用重新翻 PDF 就能快速回顾每篇文章的要点。

**笔记系统。** Zotero 的笔记支持 Markdown 语法，可以手动写文献综述、对比不同文章的方法。笔记里还能 `@` 引用你文献库里的其他条目，形成交叉链接。

## 生成引用：写论文时的杀手级功能

这是很多人装 Zotero 的初衷。Zotero 支持数千种引用格式（CSL），覆盖了几乎所有主流期刊和会议的排版要求。

**Word / WPS 插件。** 安装 Zotero 时会自动装好 Word 插件。在 Word 里写论文时，点工具栏的 Zotero 选项卡 → Add/Edit Citation，输入作者名或关键词搜索，选中后自动插入引用。写完之后点 Add/Edit Bibliography 一键生成参考文献列表。需要换引用格式？点 Document Preferences 换一种 CSL 就行，全文引用和参考文献列表自动刷新。

**LibreOffice 也支持。** 用 Linux 的同学不用担心，Zotero 对 LibreOffice 的支持同样完善。

**直接复制参考文献。** 在 Zotero 里右键一篇文献 → "创建参考文献"，可以直接复制到剪贴板，粘贴到任何地方。适合快速引用、不需要完整文档的场景。

一个常见的问题是引用格式不对。这通常是因为目标期刊的 CSL 文件不在 Zotero 的默认库里。去 [Zotero Style Repository](https://www.zotero.org/support/styles) 搜索你需要的期刊名，下载 `.csl` 文件，拖进 Zotero 就能用了。国内期刊大部分都有。

## 同步与多设备协作

前面提到，Zotero 官方提供 300 MB 的免费附件同步。如果你的 PDF 不多，这够用了。多了就不够。

**坚果云方案（推荐国内用户）。** 在 Zotero 设置里关掉"同步文件"（只保留同步文献条目），然后把附件存储目录设为坚果云的同步文件夹。这样文献条目走 Zotero 官方服务器（轻量、快），PDF 全文走坚果云（国内速度快、空间大）。两端设置一致就行。

**多设备使用。** 在另一台电脑上装好 Zotero，登录同一个账号，配置同样的同步方案，文献库就会自动同步过去。你在家里电脑做的高亮和批注，到实验室打开就能接着看。

## 进阶：和其他工具联动

Zotero 不是一个孤岛，它能和很多工具配合：

**Obsidian / Notion。** 用 [Better BibTeX](https://retorque.re/zotero-better-bibtex/) 插件导出 BibTeX，配合 Obsidian 的 Citations 插件，可以在笔记里用 `@citekey` 引用文献。学术笔记工作流直接拉满。

**浏览器标签页管理。** 装 [Zotero Connector](https://www.zotero.org/download/connectors) 之后，不仅能在学术网站抓文献，还能把普通网页保存为文献条目。适合收集技术博客、官方文档这类非正式但有价值的参考资料。

**AI 辅助阅读。** [Zotero GPT](https://github.com/MuiseDestiny/zotero-gpt) 等社区插件可以在 Zotero 里直接和 PDF 对话，问它"这篇文章的核心方法是什么"、"和另一篇文献有什么区别"。效果取决于模型，但作为辅助挺有意思。

## 小结

回到开头的问题：论文管理的核心不是"存"，而是**让文献在需要的时候能被快速找到、被方便地引用**。Zotero 解决的就是这件事——从收集到组织到阅读到引用，形成一条完整的链路。

建议的上手路径：先装好客户端和浏览器插件 → 把现有的 PDF 全部拖进去 → 建两三个分类试着组织 → 下次写论文的时候用 Word 插件插引用。跑通这一遍之后，后面的标签、笔记、同步都是锦上添花。
